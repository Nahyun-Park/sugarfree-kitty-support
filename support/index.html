현재 0.1.0 베타는 직접 기록 기능을 제공해요. 실제 AI·로그인·결제는 비활성 상태이고 서버 동기화는 없어요.

운영자에게 문의하기

운영자 및 개인정보 담당: 나나AI랩 / Nahyun Park

  1. 비공개 문의·개인정보 요청: iPhone의 TestFlight 앱 → 당끊냥 → ‘베타 피드백 보내기’를 선택하세요. 가능하면 앱 버전과 오류 문구를 적어 주세요.
  2. 공개 오류 제보·기능 제안: 아래 GitHub 문의를 이용하세요. GitHub 로그인이 필요하며 내용은 누구나 볼 수 있습니다.

GitHub에 공개 문의하기 ↗

공개 문의에 이메일·건강 기록·사진·백업·인증코드·결제 정보를 넣지 마세요. 개인정보 요청도 TestFlight 비공개 피드백으로 보내 주세요.

기록을 안전하게 옮기려면?

앱의 내 정보에서 기록 백업을 내려받고 파일에 저장하세요. 새 기기에서 해당 파일을 가져오면 복원할 수 있습니다. 로그인이나 TestFlight 업데이트만으로 기록이 다른 기기에 동기화되지는 않습니다. 앱 삭제 전 백업을 확인해 주세요.

저장·복원이 실패했어요

기기 여유 공간을 확인하고 원본 백업 파일을 별도로 보관하세요. 오류 문구가 보이면 무리하게 초기화하지 말고 문의해 주세요. 당끊냥은 운영자 서버에 기록 사본을 보관하지 않아 삭제된 기기 기록을 원격 복구할 수 없습니다.

사진 결과가 실제 기록인가요?

데모는 기록이나 연속 기록에 포함되지 않습니다. 실제 음식 기록은 라벨과 분량을 확인해서 직접 입력하세요. 총당류와 첨가당은 다르며 모르는 값은 0g이 아닙니다.

돈이 청구되었나요?

이번 베타는 인앱 구매를 제공하지 않습니다. Apple에서 예상하지 못한 청구가 보이면 Apple 구입 내역·문제 신고에서 해당 항목을 확인하세요. 문의에 영수증 전체나 카드번호를 첨부하지 마세요.

건강과 마음이 걱정될 때

앱은 의료 도구가 아닙니다. 개인 건강 상태는 의료진과 상의하고 음식에 대한 불안이나 반복적인 식사 제한으로 힘들면 신뢰할 수 있는 사람 또는 전문가에게 도움을 요청하세요.

Support · English

Contact Nana AI Lab / Nahyun Park. For private support or privacy requests, open TestFlight → Sugarfree Kitty → Send Beta Feedback. For public bug reports or suggestions, open a GitHub issue (GitHub sign-in required). Public issues must not contain personal records, photos, email addresses, backups, verification codes or payment details.

Include app/device/OS versions, the error message, time and steps. Export a backup in Profile before deleting the app or changing devices; import that file on the destination device. There is no server sync. If storage or restoration fails, keep the original backup, check free device space and contact support before resetting. We cannot remotely restore deleted device records.

Demo scans do not affect intake or streaks. Check real labels and portions before logging; unknown added sugar does not mean zero. This beta offers no in-app purchases. For an unexpected Apple charge, review Apple purchase history. Never send full receipts or card numbers in public reports.

The app is not a medical tool. Ask a clinician about health conditions, and seek trusted or professional support for persistent food-related distress.
