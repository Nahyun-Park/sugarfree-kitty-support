이 방침은 나나AI랩 / Nahyun Park(이하 운영자)가 제공하는 당끊냥 TestFlight 0.1.0 베타와 이 지원 사이트에 적용됩니다.

1. 기기 안에 보관하는 정보

체크인, 음식명·첨가당 추정량·날짜, 습관 설정, 고양이 이름과 꾸미기, 언어 설정은 앱의 기기 저장 공간에 보관됩니다. 이 베타는 해당 기록을 운영자의 서버로 전송하거나 기기 간 동기화하지 않습니다. 기기 접근 권한이 있는 사람은 기록에 접근할 수 있으므로 기기 잠금을 사용해 주세요.

2. 사진·대화·계정·결제

이번 베타의 사진 예시는 데모이고 코치는 규칙 기반 안내입니다. 실제 사진 분석과 외부 AI 전송은 꺼져 있습니다. 계정 로그인 및 인앱 구매도 꺼져 있어 이메일 인증 정보나 구독 정보를 당끊냥 서버에 수집하지 않습니다. 실제 AI 또는 계정 기능을 제공하기 전 전송 항목, 처리 업체·지역과 보관 기간을 안내하고 필요한 동의를 받습니다.

3. 내보내기와 삭제

사용자가 백업 또는 이미지 공유를 선택하면 파일이 기기에 생성되고 사용자가 선택한 저장 위치·앱으로 전달됩니다. 공유 대상 서비스의 정책이 적용됩니다. 백업에는 개인 기록이 포함되므로 공개 장소에 올리지 마세요. 내 정보에서 기록을 초기화하거나 앱을 삭제하여 기기 기록을 제거할 수 있습니다. 별도로 내보낸 파일과 기기·클라우드 백업은 직접 삭제해야 합니다. 운영자는 기기 기록을 원격으로 열람하거나 복구할 수 없습니다.

4. TestFlight 피드백과 문의

Apple은 TestFlight 이용과 관련하여 기기·앱 버전, 충돌 및 사용 진단, 사용자가 보낸 설명·스크린샷과 관련 연락 정보를 처리하고 일부를 개발자에게 제공합니다. 운영자는 제공받은 내용을 오류 확인과 문의 응대에만 사용합니다. 운영자가 별도로 내려받은 피드백 사본은 문의 종결 후 90일 이내 삭제하며 법률상 보존이 필요한 경우 해당 의무 범위에서만 보관합니다. Apple 서비스 자체의 보관·삭제는 Apple TestFlight 개인정보 안내를 따릅니다.

GitHub 문의를 사용하면 사용자명과 작성 내용이 공개됩니다. 개인정보·건강 기록·사진·인증코드 등을 공개 이슈에 올리지 마세요. 비공개 내용은 TestFlight의 피드백 보내기를 사용하세요.

5. 웹사이트

이 사이트는 GitHub Pages로 제공됩니다. 운영자는 별도의 광고, 추적 분석, 외부 폰트 또는 쿠키 도구를 추가하지 않습니다. GitHub는 사이트 제공과 보안을 위해 IP 주소 등 접속 정보를 처리할 수 있습니다. GitHub의 처리·보관 및 권리 행사는 GitHub 개인정보처리방침을 확인해 주세요.

6. 문의와 권리 행사

개인정보 담당: 나나AI랩 / Nahyun Park. 운영자에게 제공한 정보의 열람·정정·삭제 또는 처리 문의는 지원 페이지의 TestFlight 피드백 경로로 요청할 수 있습니다. 본인 확인에 필요한 최소 정보만 요청합니다. 기기 기록은 앱에서 직접 관리할 수 있습니다. Apple·GitHub가 독립적으로 처리하는 정보는 해당 업체의 권리 행사 경로도 이용할 수 있습니다.

7. 변경 안내

방침을 바꾸면 이 페이지의 시행일과 변경 사항을 갱신합니다. 데이터 처리 범위가 달라지는 기능은 변경 사항을 안내하고 필요한 동의를 받기 전 활성화하지 않습니다.
